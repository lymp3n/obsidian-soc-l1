# Без названия

## 📖 IP-адрес
IP-адрес (Internet Protocol — адрес) — это адрес устройства в интернете. Он представляет собой набор правил (протоколов) и используется для адресации и передачи данных по сети.

IP-адреса классифицируют в зависимости от: 

протоколов (правил), регулирующих формат данных,
назначения IP-адреса, 
сменяемости IP-адреса. 

Существует два набора протоколов передачи данных. Их ключевое отличие — количество допустимых адресов: 

IPv4 — содержит 4,3 миллиарда адресов, 
IPv6 — содержит 79 228 162 514 264 337 593 543 950 336 октиллионов адресов. 

# Назначение:

Внутренний IP (он же частный, локальный, «серый») — находится в диапазоне, не имеющем доступа к интернету. Такие адреса используются в локальных сетях и контролируются только администраторами данных сетей. 
-192.168.0.0 — 192.168.255.255 (для малых и домашних сетей)
-10.0.0.0 — 10.255.255.255 (для крупных сетей и офисов)
-172.16.0.0 — 172.31.255.255 (для корпоративных систем

Внешний IP (он же публичный, глобальный, «белый») — присваивается только одному конкретному компьютеру. Доступ к компьютеру с таким адресом можно получить из любой точки глобальной сети, а «общение» с внешними серверами и другими компьютерами происходит напрямую, от устройства к устройству. Ответственность за использование публичного IP-адреса лежит на пользователе.

# Сменяемость:

Статический IP-адрес — постоянный адрес, который назначается при подключении устройства к сети. Этот адрес имеют все сайты, потому что он позволяет пользователю получить доступ к тому же серверу, что и ранее. 

Динамический IP-адрес — это адрес, который меняется при каждом новом подключении устройства к сети. Такой адрес «выдаётся» пользователю на время, а потом провайдер присваивает его другому пользователю, поскольку набор IP-адресов ограничен.
