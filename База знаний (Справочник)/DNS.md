# DNS (Domain Name System)

## 📌 Суть (TL;DR)

> **DNS** — это адресная книга интернета. Компьютеры общаются между собой с помощью числовых IP-адресов (например, `142.250.190.46`), но людям удобнее использовать текстовые имена (например, `google.com`). DNS автоматически переводит введенное человеком имя в нужный IP-адрес.

## ⚙️ Механика работы / Архитектура

- **Протокол и порт:** В основном использует **UDP/53** для скорости. Если данных слишком много, переключается на **TCP/53**.
- **Как происходит поиск:** Когда вы вводите адрес сайта, запрос проходит иерархию:
  1. **Локальный кэш:** Ваш компьютер проверяет, не сохранял ли он этот адрес ранее.
  2. **Root (Корневые серверы):** Указывают путь к серверам верхнего уровня (TLD).
  3. **TLD (Top-Level Domain):** Серверы зон (например, `.com`, `.ru`). Они знают, где находится сервер конкретного сайта.
  4. **Authoritative (Авторитативный сервер):** Сервер, который хранит точную запись и отдает финальный IP-адрес.

## 🛡️ Фокус ИБ (Атаки / Логи / Защита)

**⚔️ Векторы атак:**
1. **DNS Spoofing (Подмена DNS / Cache Poisoning):** Злоумышленник вмешивается в процесс запроса и подменяет IP-адрес легитимного сайта. В результате пользователь вводит `bank.com`, но попадает на точную копию сайта, созданную хакером для кражи паролей.
2. **DNS Amplification (DDoS-атака):** Хакер отправляет небольшой запрос к уязвимому DNS-серверу, но подделывает обратный адрес (IP-адрес жертвы). Сервер генерирует огромный ответ и отправляет его жертве. Так хакер многократно усиливает (амплифицирует) мощность атаки, перегружая канал жертвы.
3. **DNS Tunneling (Туннелирование):** Поскольку большинство компаний не блокируют DNS-трафик (без него не работает интернет), хакеры упаковывают команды управления вирусом или украденные данные внутрь длинных нестандартных DNS-запросов, незаметно пронося их мимо систем защиты.

**🛡️ Защита:**
- **DNS Sinkhole:** Механизм защиты, при котором запросы к известным вредоносным доменам (серверам хакеров) перенаправляются на внутренний «пустой» IP-адрес. Вирус в сети теряет связь со своим хозяином.
